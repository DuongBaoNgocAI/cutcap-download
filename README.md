# CutCap — Tải bản cài

Công cụ ghép video AI khớp giọng đọc qua phụ đề SRT.

## Tải về

Vào mục **[Releases](https://github.com/DuongBaoNgocAI/cutcap-download/releases/latest)** và tải file phù hợp:

| Hệ điều hành | File tải |
|---|---|
| 🪟 **Windows** | `CutCap.Setup.<phiên bản>.exe` |
| 🍎 **macOS** (Intel & Apple Silicon) | `CutCap-<phiên bản>-universal.dmg` |

## Hướng dẫn cài đặt (khi máy báo chặn)

- **Windows** — "Windows protected your PC": bấm **More info → Run anyway**.
- **macOS** — "không thể xác minh nhà phát triển": **chuột phải vào app → Open → Open**, hoặc vào **System Settings → Privacy & Security → Open Anyway**.

Cảnh báo này chỉ vì app chưa mua chứng chỉ ký số, **không phải virus**. Chỉ tải CutCap từ trang này.
